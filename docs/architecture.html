API Endpoints

GET
/api/inventory
All inventory items — filters: warehouse, category
GET
/api/orders
Orders — filters: warehouse, category, status, month
GET
/api/dashboard/summary
Aggregated KPIs — supports all filters
GET
/api/demand
Demand forecasts — no filters
GET
/api/backlog
Backlog items with purchase order status
GET
/api/spending/*
Summary, monthly, categories, transactions
GET
/api/reports/quarterly
Quarterly performance aggregation
GET
/api/reports/monthly-trends
Month-over-month order trends
